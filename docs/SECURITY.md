# セキュリティとデータの扱い

## 外部へ出ないこと

- 推論は同梱の llama.cpp(llama-server)で行い、`127.0.0.1` でのみ待ち受けます。書類の画像・文字が端末(サーバー)の外へ送られることはありません。
- インターネットへ接続するのは、初回の VLM 導入(llama.cpp の配布物と公開モデルのダウンロード)だけです。オフライン環境では、別の端末で用意した `bin/llama` と `models/` をコピーすれば接続不要です。
- 推論先に「別の推論サーバー(OpenAI 互換)」や Ollama を選んだ場合は、その URL へ書類画像を送ります。LAN・ローカル以外の URL を設定するとログに警告が出ます。
- テレメトリ・利用状況の送信は一切ありません。

## 保存されるもの

インストーラで入れた場合は `%LOCALAPPDATA%\EAGLE\`、ポータブル版とソースから動かす場合はアプリのフォルダの `data/` に保存されます(`storage.data_dir` / 環境変数 `EAGLE_DATA_DIR` で変更可)。アンインストールしてもデータは消えません。

| 場所 | 内容 |
|---|---|
| `data/eagle.db` | 抽出結果・マスタ・設定・学習・利用者(パスワードはハッシュのみ) |
| `data/files/<id>/` | 原本・ページ画像・単語座標 |
| `data/logs/` | アプリと llama-server のログ |
| `data/secret.key` | アプリ固有の鍵 |

バックアップは `data/` フォルダごとコピーしてください(アプリ停止中が安全)。
**このフォルダや業務書類・マスタをリポジトリに追加しないでください**(`.gitignore` で除外済み)。

## アプリ版

- API は `127.0.0.1` でのみ待ち受け、Host ヘッダも検証します(DNS リバインディング対策)。
- 書き込み系の API は独自ヘッダ必須(他サイトからの CSRF を防止)。

## Webアプリ版

- ログイン必須。パスワードは PBKDF2-SHA256(39万回)で保存。同じ利用者・端末からの連続失敗(5回/5分)は一時ロック。
- セッションは HttpOnly / SameSite=Lax の Cookie。HTTPS で配信した場合は Secure 属性も付きます。
- 権限: 管理者(設定・利用者・マスタ・外部DB)/ 編集者(取込・修正・確定・テンプレート)/ 閲覧者(閲覧・出力)。
- インターネットから到達できる環境では必ず HTTPS(`server.ssl_certfile` / `ssl_keyfile`)またはリバースプロキシを使ってください。
- 外部DB の接続 URL(パスワードを含む)はアプリ内 DB に保存され、画面・API ではパスワードを伏せて表示します。
