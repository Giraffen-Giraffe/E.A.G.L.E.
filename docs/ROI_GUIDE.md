# ROI(読取領域)で精度を上げる

E.A.G.L.E. はテンプレートが無くても様式に依存せずに読み取ります。
ただし、特定の発行元で同じ読み違いが続く場合は、その発行元のテンプレートに **ROI** を追加すると改善します。

## よくある読み違いと対策

| 症状 | 対策 |
|---|---|
| 発注元と届け先(物流センター・受入場所)が逆になる | 発注元の欄に `発注元ブロック(@buyer)` の ROI |
| 発注担当者が取れない・別人になる | 担当者が書かれた欄に `発注担当者` の ROI(補足指示:「この欄には発注担当者の氏名だけが書かれている」) |
| 届け先が空になる | 納入先の欄に `納品先ブロック(@ship_to)` の ROI |
| 注文番号の桁落ち・別の番号を拾う | 注文番号の欄に `注文番号` の ROI + 書式(例 `[A-Z]{2}\d{4}-\d{6}`) |
| 明細の小さい文字・かすれを読み違える | 明細表全体に `明細表の範囲(@line_items)` の ROI(拡大して読み直す) |

## 手順

1. 対象の書類を開き、「ROI を追加・編集」を押す(その書類を見本にテンプレートが作られ、発注元の社名が判定キーワードに入ります)。
2. 左の画像上をドラッグして領域を描き、右で「書き込み先」を選ぶ。
3. 「この ROI を試し読み」で読み取り結果を確認し、位置や補足指示を調整する。
4. 「保存」→「見本を再処理」で全体の結果を確認する。以後、同じ発行元の書類には自動で適用されます。

## 設定項目

| 項目 | 説明 |
|---|---|
| 書き込み先 | 標準項目・追加項目、またはブロック(@buyer / @ship_to / @line_items) |
| ページ | 対象ページ。明細範囲は 0 で全ページ |
| 読み方 | 自動(電子PDFは文字情報、画像は VLM)/ 常に VLM / 文字情報のみ |
| 反映 | 読めたら上書き / 全体読取で空の時だけ |
| 補足指示 | VLM への追加の説明 |
| 書式 | 正規表現。合わない読みは捨てる |

## スキャン位置のズレ

テンプレートの「スキャン位置のズレを自動補正」を ON にすると、見本の書類と処理中の書類それぞれの
**印字範囲**(余白を除いた範囲)を基準に ROI の位置を写します。FAX やスキャナで紙の位置・倍率が
多少ずれても ROI が正しい欄に乗ります。スキャン画像は取込時に傾きも自動で補正されます。

## テンプレートのその他の設定

- **判定キーワード**: 社名(VLM が読んだ会社名)・本文・ファイル名に含まれればこのテンプレートを使う。`re:` で始めると正規表現。
- **読取ヒント**: 発行元の癖を VLM に伝える(全体読取と明細読取の両方に入る)。
- **書式**: `order_number=正規表現` のように項目ごとの書式。合わない値は本文や他の欄から書式に合う値を探して補正する。
- **既定値 / 固定値**: 空欄なら補う値 / 常に上書きする値(例: `buyer_code=1001` でこの発行元の顧客コードを固定)。

## 学習との関係

確定時の修正は学習され、同じ読み違いは次回から自動で直ります。
「学習」画面の「修正の多い項目」に **ROI 追加を推奨** と出た項目は、読み取り自体を改善するために ROI を足すのが効果的です。
